YASIR HUSSAINI — EASY-EDIT PORTFOLIO

START HERE
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Click the floating “Edit website” button at the bottom-right.
4. Tap any outlined text and edit it directly.
5. Click “Save changes” in the green bar. Text saves in that browser on that device.
6. Click “Done editing” to return to normal view.

PHOTOS
- In the profile panel, click “Upload profile photo” and choose an image from your phone/computer.
- In Photo Gallery, click “Add gallery photo” to add images and edit their captions.
- Browser storage can have size limits. Keep copies of your original images.
- Photos added in the browser are not automatically written into index.html. For a public website, place image files in a folder and update the HTML or use the browser preview as a guide.

EDITING THE SOURCE CODE
You can also open index.html in a code editor (for example, VS Code on a computer). It is a single-file website: design and JavaScript are included in the HTML so it is easier to manage. The CSS and JavaScript are embedded in index.html.

PUBLISHING
For a public site, upload index.html to a static hosting service such as GitHub Pages. The visual editor's localStorage changes are saved only in that browser, not automatically to the hosted website. To publish edited text/photos, copy the edits into the source file or use a code editor and upload the updated file.

BEFORE USING FOR SCHOLARSHIPS
Verify the spelling of your name, school and institute names, scores, dates, and experience. Replace email and social links. Proposed project ideas are labeled as proposed—do not present them as completed projects.
